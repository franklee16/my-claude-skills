# Pre-Send Checklist — R&R Response Letter

Merged audit criteria from the strategy guide (§8 red lines, §10 checklist, §9 failure taxonomy) and the style guide (§3, §8, §10). Written as questions asked OF THE ARTIFACT — a critic with only the letter, the extracted comments, and the guides must be able to answer every one. Source tags name the rule's home.

## Triage [strategy §2, §10]

- [ ] Is the acceptance condition identified and does the summary-of-major-changes block mirror it, in order?
- [ ] Is every comment coded (threat × type), with response amplitude allocated by threat — structural over-compliance on identification/contribution threats, full literal compliance on robustness demands, one-sentence exact compliance on presentation notes?
- [ ] Are cascade-risk comments given protocols rather than one-shot answers?
- [ ] Round ≥2: are re-raised comments marked, prior hatches/promise fulfilled or explicitly addressed?

## Moves [strategy §3, §4, §8; style §4]

- [ ] Zero frontal disagreement anywhere — and zero *evaluative discounting* of the referee's priorities ("not an important concern", "does not add much value")? [red line 1, 8]
- [ ] Zero run-then-refuse combinations (analysis executed, incorporation declined)? [red line 2; §9 Failure 2]
- [ ] Zero cuts of referee-requested evidence? Cuts, if any, are own indefensible claims with the evidentiary admission stated in the letter? [red line 3; §4.10]
- [ ] Does every direct question from the referee get an explicit answering sentence? [red line 4; §9 Failure 7]
- [ ] Does every decline / kept-preference decision carry an escape hatch? [red line 5; §9 Failure 5]
- [ ] Is any scope-declaration ("beyond the scope") aimed at anything the referee marked decision-relevant? [red line 5; §9 Failure 4]
- [ ] Is every apology attached to an objective error only, exactly one per error?
- [ ] Is every concession monetized — converted into robustness, mechanism evidence, or goodwill — rather than a bare surrender? [strategy §6]

## Evidence [strategy §5, §10]

- [ ] Do new tests execute the referee's design where he specified one? Oversupplied where identification is at stake?
- [ ] Is the referee's premise tested before the paper's own result is defended? [§4.1 step 3; §5.2]
- [ ] Is every new table walked column by column, with attenuation disclosed and t-stat stability as the operative statistic?
- [ ] Is every magnitude benchmarked (paper's own moments, literature, or unconditional baselines)?
- [ ] Are exceptions counted rather than asserted away ("only the X anomaly shows…")?
- [ ] Do event-style estimates carry pre-window nulls?
- [ ] Are unfavorable sub-results disclosed — and, where they protect load-bearing claims, in the main text?
- [ ] Does placement follow §5.1 — and does nothing the referee demanded sit only in the letter or appendix against an incorporation demand?

## Portfolio [strategy §7, §10]

- [ ] Was the one-construction-many-debts scan done (does any single new construction pay multiple comment debts)?
- [ ] Multi-referee: stricter-referee rule applied; identical arbitration sentence in all letters; no letter contradicts another; favorable-referee leverage cited where available?
- [ ] Can the editor verify and defend an accept from the letter alone — mirror tables, verbatim pastes, page pins, migration list, quantified page counts?
- [ ] Are old→new mappings complete and consistent across letters?

## Compliance & voice [style §2, §3, §8, §10]

- [ ] Is every referee comment reproduced verbatim, in italics, with original numbering and nested structure preserved — verified line-by-line against the extracted source?
- [ ] Does every response open with the gratitude ritual before substance?
- [ ] Is the voice first-person plural throughout, addressing the referee in the second person?
- [ ] Are actions stated declaratively in present-perfect, interpretations hedged per the two-register rule?
- [ ] Does every response carry a precise manuscript pointer (Section/page/footnote/table) — and is every pointer traceable to an input artifact (no fabricated locations)?
- [ ] Is every number paired with its t-statistic, every magnitude with a benchmark?
- [ ] Is pasted revised prose quoted verbatim as block quotes as proof of completion?
- [ ] Do response-only exhibits use the R-prefix sequence, separate from manuscript numbering, with full captions and notes?
- [ ] Is the letter's structural convention (title block, opening framing, summary block, per-comment loop, references, closing) internally consistent — one numbering style, one response-label convention?
- [ ] Zero unresolved placeholders ("page XX", "[CONFIRM]", "[TBD]", "copy that section")?
- [ ] Zero source-pair tags ([P1]…[P8]) or sidecar provenance comments leaked into the visible letter?
- [ ] Is every stylistic phrasing traceable to the style guide's phrase banks (§5/§6) — with any gap reported rather than papered over?

## Escalation [strategy §8; global revision protocol]

- [ ] Was any comment requiring pure disagreement escalated to the author before drafting?
- [ ] Are DISAGREE classifications genuine hard-gate outputs — neither skipped nor over-applied?
